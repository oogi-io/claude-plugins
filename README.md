# OOGI plugins for Claude Code

The `oogi` marketplace. Add it once, then install what you need:

```bash
claude plugin marketplace add oogi-io/claude-plugins
claude plugin install fm-odata@oogi
```

| Plugin | What it is | Repository |
|---|---|---|
| `fm-odata` | Point your AI here and it'll be able to work with OData. FileMaker OData behaviours that return wrong data instead of errors, with the evidence per claim. | [oogi-io/fm-odata-skill](https://github.com/oogi-io/fm-odata-skill) |
